# Ejercicios de JavaScript: funciones y arrays

Práctica del bootcamp para trabajar funciones, arrays, bucles y condicionales.

## Ejercicios

1. Guardar una tabla de multiplicar en un array.
2. Pedir números y ordenarlos de menor a mayor.
3. Comprobar si un año es bisiesto.
4. Contar un carácter dentro de un array de palabras.

## Cómo ejecutarlo

Abrir index.html en el navegador y consultar los resultados en la consola.
